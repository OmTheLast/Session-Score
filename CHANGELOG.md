# Changelog

## [0.2.0-beta.1] — 2026-11-11

- The free Apple silicon Mac beta reads local Codex sessions directly. The ZIP includes the runtime and opens as a desktop app.
- The website includes first-open instructions and an interactive browser demo with the same music engine and fictional session events.
- The local browser server now returns HTTP 400 for a malformed request and continues serving the dashboard.

## [0.1.0] — 2026-11-09

### Added

- A local dashboard turns activity across Codex sessions into one live soundtrack.
- Ten bass melodies share a beat with keys, chords, drums and fills triggered by agent actions.
- Three presets include a mixer and per-action controls for sound, variation and phrase length.

### Changed

- Saved action lengths double once on upgrade. Normal completion fades sounding notes for up to 0.8 seconds.
