# Ten electronic sketches

Each sketch is twelve seconds long. A scripted tool call introduces the lead around two seconds in. The call repeats around five and a half seconds, splitting the last note into two pulses. The turn ends around nine and a half seconds. Each arrangement snaps those events to its own beat.

[Play the full two-minute sampler](electronic-sampler.mp3). Pick the numbers you want to hear in a live session.
